# TOY·LINK 装置模拟器

给 SillyTavern（酒馆）用的一套遥控震动装置模拟器：手机 App 式的遥控界面，选模式、调频率与强度，装置状态实时同步给角色，角色据此给出身体反馈。

装到任意角色卡上都能用 —— 脚本自己会把通用世界书设定写进去，不需要你另外配提示词。

> **成人向内容**。默认的世界书条目包含露骨的性描写（强度档位对应的身体反应、男女两版生理机制、九种模式的体感）。不需要的话可以在脚本设置里关掉自动建库，自己写一份。

## 装

**需要 [酒馆助手（Tavern Helper / JS-Slash-Runner）](https://github.com/N0VI028/JS-Slash-Runner)。**

### 装法：导入 `TOY-LINK脚本.json`（推荐）

1. 酒馆助手 → **脚本** 标签 → 工具栏点 **导入**（向下箭头的文件图标）
2. 目标选 **全局**（所有角色都能用）/ 当前角色卡 / 预设
3. 文件框里选 `TOY-LINK脚本.json`
4. **手动打开它右边的开关**

> 第 4 步不能忘。酒馆助手导入脚本后会强制设成禁用状态，开关不开就是「看着有、功能没反应」。

**装这一次就够。** 之后作者发版，你刷新酒馆页面就是新版，不用重新导入。

**它是怎么自动更新的**：脚本启动时会问一次版本指针（一个只有几行的文本文件），发现比自己新，就把**脚本库里的自己**替换成新本体。所以更新过的本体存在你本地，**之后断网也照常工作**。

> **为什么不做成一行 `import` 链接**：试过，两头都堵死。
> `import` 加载的是 ES 模块，规范要求服务器返回 JavaScript 的 MIME —— jsDelivr 给 `application/javascript`，但它对固定网址的响应头是 `Cache-Control: max-age=604800`，**浏览器缓存 7 天**，而且 purge 只清 CDN 那一层，够不着浏览器，热更新失效；GitHub raw 缓存只有 5 分钟，但给的是 `text/plain` 加 `X-Content-Type-Options: nosniff`，`import` **直接被浏览器拒绝执行**。
> 四个 jsDelivr 镜像（cdn / testingcf / fastly / gcore）的缓存头完全一样，换域名也没用。
> 所以只能自己用 `fetch` 拉（**fetch 不看 MIME**），再写回脚本库。

### 或者：手动粘代码

不想导入文件的话，用文本编辑器打开 `TOY-LINK脚本.json`，把 `content` 字段那一整段复制出来，脚本库里新建脚本直接粘贴 —— 效果和导入一样。

### 然后

1. 刷新酒馆页面，右下角出现一个紫色小悬浮球（C 形装置的样子）。
   - 按住能拖，松手会弹到最近的左边或右边，位置记在本地。
   - 装置运行时它跟着实时节奏动：机身颜色随强度变暖、金环上的小灯亮、每个波峰从头部放一圈声波、球外一圈晕光表示强度（TA 拿遥控器时换成红色）；临界爆发时连放三圈。不做抖动——看久了烦。
   - 手机开了「减少动态效果」的话只留颜色和小灯，不放声波。
   - 没看到就点脚本按钮「TOY·LINK 控制器」试试。
   - 还是没有就按 F12 看控制台，搜 `[TOY·LINK`，更新检查和挂载都有日志。
2. 点「启 动」，选模式，调频率与强度。

**换过脚本之后如果界面没变**，多半是旧脚本还跑着。从 v1.10.5 起新版会自动把旧实例拆掉接管；更早的版本要先在脚本库里把旧的删掉。

**世界书不用你管**：脚本启动时会自动写一本「TOY·LINK 装置设定」并挂到当前角色卡。不想让它自动写，在设置页关掉「自动建立并绑定世界书」即可。

## 界面

三页，底部切换。

**装置页** —— 圆环是实时强度，下面依次是九种模式、频率/强度/限时三条滑杆、启动键。

九种模式：脉冲（短促点动）、潮汐（绵长起伏）、心跳（双拍重击）、渐强（缓慢爬到顶再落下）、乱流（毫无规律）、撩拨（长时间空着偶尔来一下）、暴雨（密集连击）、临界（顶在高位再突然撤走）、冲刺（短时间直冲顶点，到顶后自动停下）。

**TA 的反应页** —— 角色的回应进这里，顶部有输入框可以直接对 TA 说话。

**设置页** —— 发送方式、描写尺度（露骨 / 忍耐）、世界书、注入、冻结、震动开关等，还有一份「状态快照」，写的是角色实际能看到的内容，排错时看这个最直接。

**悬浮球**（设置页里一节，只存在这台设备上）—— 大小三档；底盘透明度三档（只调装置后面那块奶白圆盘，装置本体不变；待机时整球微暗，运行 / 按住 / 悬停回实心）；**隐藏悬浮球**（只用脚本按钮「TOY·LINK 控制器」开面板，按钮在快速回复栏里，装了 QR 整合插件的在火箭菜单里）；**贴边半藏**（手机上球靠边几秒没人碰就半藏进边里，点它或装置跑起来会出来）。

## 三个开关

**作用对象**（面板最上方，两段式）

| 档位 | 装置在谁身上 | 遥控器 | 面板形态 |
|---|---|---|---|
| 你拿着遥控器（默认） | 角色 | 玩家 | 粉色，档位随便调 |
| TA 拿着遥控器 | 玩家 | 角色 | 红色，档位点不动，多一个「请求 TA 停下」 |

后一档里因果是反的 —— 由 TA 决定档位，你在回复末尾的装置读数里看到结果，界面才跟着变。装置运行中切换器会锁住：换对象要整本重写世界书，而装置还带着上一个对象的运行状态，两边对不上。

**身体反应**（女性 / 男性）

决定被作用者的身体按哪一套写。女性版强调没有不应期、顶点之后更敏感；男性版强调顶点是一次性释放、之后有不应期，不写连续高潮。

**露骨描写**（默认开）

| 档位 | 写什么 |
|---|---|
| 开 · 直写 | 体内的感觉、装置怎么震、顶点怎么来，照写 |
| 关 · 忍耐 · 假装镇定 | 不写体内，只写看得见听得见的：呼吸、姿态、手在抓什么、话说得完不完整、声音从哪漏出来、被碰倒的杯子。顶点只写「装不住了」的那一下 |

关掉这一档换的不是措辞，是描写的方向：由「体内在发生什么」改成「对周围世界失去了多少控制」——手比嘴诚实，声音比表情诚实。整份条目按这个方向重写了世界书的 ④⑧⑪ 三条，⑤⑦⑨ 末尾各追加一段（男女各有一版外部表现条目）。

它改的是**脚本自动建的那本世界书**。用角色卡自带世界书（或自己手写的那本）时，世界书那一半改不到，这时靠状态注入里那条同款禁令兜底——注入在提示词最前，压得住。

## 震动

两个独立开关，管的是两件事：

- **按键震动**（默认开）—— 操作手感：切模式、启停、切换作用对象各给一下不同长度的短震
- **跟随震动**（默认关）—— 装置运行时按实时频率一直震

后者默认关着，因为手机马达分辨不出频率，实际听到的是断续的哒哒声；持续运转也费电发热。

**iOS / Safari 全平台没有震动接口**，这两个开关在 iPhone 上不起作用，想要手感就用「声波模拟」代替。

## 常见问题

| 现象 | 原因 |
|---|---|
| 悬浮球不出现 | 酒馆助手没装或没启用；看控制台有没有 `[TOY·LINK] 已挂载到 酒馆页面`，看到 `via self` 说明找不到酒馆页面 |
| 角色不知道该怎么反应 | 世界书没挂上。设置页确认「自动建立并绑定世界书」开着，或手动导入 |
| 装置状态正常但 AI 不吭声 | 「自动反应」关着，或者反应冷却还没到。点「立刻反应一次」 |
| 正文里装置戴到了玩家身上 | 设置页的「作用对象」被切到了「TA 拿着遥控器」。切回来，或者开个新聊天 |
| 悬浮球挡字 / 太大 | 设置页「悬浮球」一节：调小、底盘调透、开贴边半藏，或干脆隐藏只用脚本按钮 |
| 改了代码但用户还是旧版 | jsDelivr 的 `@main` 缓存，最长 12 小时。作者走一次 purge 刷新 |
| 关掉露骨描写，反应还是照旧露骨 | 世界书用的是角色卡自带的那本，脚本管不到它。设置页打开「自动建立并绑定世界书」，世界书那一半才会跟着开关走 |

## 自己改

仓库里带源码，是这一条链：

```text
index.html  ──(node 工具-构建脚本版.js)──▶  dist/TOY-LINK-<版本>.js
  源码                                        产物（用户脚本自更新时拉的就是它）
```

**改完源码必须重跑构建再提交**。构建会同时写出三样东西：`dist/TOY-LINK-<版本>.js`、`version.txt` 的指针，以及 `TOY-LINK脚本.json` 里的本体。**三者版本号必须一致** —— 不一致的话用户的自更新会拉到错的东西，或者干脆拉不到。

```powershell
git clone https://github.com/fJForever/toy-link.git
cd toy-link
node 工具-构建脚本版.js      # 零依赖，只要 Node
```

不需要 `npm install`，构建脚本只用 Node 内置模块。

`index.html` 按注释分了十二段，都能找到对应位置。加震动模式在 `MODES` 数组里追加一项；两套主题配色是 `:root` 和 `#shell.tgt-user` 里的两组 CSS 变量，改那两组数值就能整机换色（记得同步 `THEME_RGB` —— canvas 读不到 CSS 变量）。

自定义许可是禁止二改发布的，所以改完自己用没问题，发出去要先问作者。
